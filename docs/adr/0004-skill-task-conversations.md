# Skill 任务对话复用受控执行器

应收账款合并与销售拆分作为首个试点，在工具运行页使用独立的 AI 对话。服务端只提供当前授权 Skill 的目录与已发布 SKILL.md；模型通过 prepare_task_draft 绑定用户选中的文件和参数，确认后的任务仍由现有 Worker 与 Python 脚本执行。

试点通过平台受控名单开放，不根据外部包加载任意前端代码，也不授予模型运行系统命令的能力。后续新增工具需明确其输入契约、风险和执行能力，再进入名单。现有核销工作流继续使用原入口。

草稿确认沿用权限、Skill 哈希、文件哈希与幂等校验。任务对话保存草稿标识，恢复时读取服务端真实草稿状态；材料改变使旧草稿失效。工具与通用助手的历史按会话范围隔离，切换时取消旧的恢复请求。结果在原对话页显示，也可从任务中心查看。

本期只打通已有确定性脚本的模型调用，不包含任意标准 Skill 上传后的自动适配，也不授权模型改写业务规则或财务原件。
