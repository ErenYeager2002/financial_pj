# 08 完成筛选空态、小屏和无障碍改造

Status: ready-for-human
Category: enhancement
Priority: P2
Blocked by: 04, 06, 07

## Agent Brief

**Category:** enhancement
**Summary:** 统一任务中心在小屏和辅助技术下保持完整、清晰且可操作。

**Current behavior:**
页面公共标题从 `h2` 开始。普通任务使用六列表格，小屏依赖横向滚动；状态、进度、日期和操作难以同时查看。部分异步提示没有告警语义，筛选空态与首次空态缺少可访问的区分说明。

**Desired behavior:**
任务中心拥有唯一的一级标题。桌面可使用表格或宽屏列表，小屏改为任务卡片，只保留类型/任务名、业务日期、状态、进度和主要操作，次要信息合理折叠。状态不能只靠颜色表达，加载、错误、筛选结果数量和分页变化对辅助技术可感知。

**Key interfaces:**
- 页面标题组件 — 支持页面唯一 `h1`，不破坏其他页面标题层级
- 任务中心条目列表 — 提供桌面和小屏语义一致的响应式表现
- 状态与进度 — 同时提供文字、可访问名称和适当的实时区域
- 筛选空态与区域错误 — 标题、说明和操作具有正确焦点与告警语义

**Acceptance criteria:**
- [x] 任务中心只有一个可见 `h1`，后续区域标题按顺序使用下级标题
- [x] 小屏无需横向滚动即可看到每项的类型/名称、业务日期、中文状态、进度和主要操作
- [x] 桌面与小屏使用相同数据和详情目标，不因响应式布局隐藏失败摘要或下一步操作
- [x] 状态不只依赖颜色，进度具有可访问名称和值
- [x] 异步错误、刷新成功和筛选结果变化能够被辅助技术感知且不会重复播报轮询更新
- [x] 键盘可以依次操作筛选、清除筛选、分页、提醒和任务详情入口
- [x] 响应式结构、标题层级、告警语义和键盘操作具有自动化测试

**Out of scope:**
- 重设计全站所有页面的标题和响应式布局
- 引入新的 CSS 框架或组件库
- 修改任务中心条目的后端字段
