# 业务流程与状态判断

## 登录与导航

1. 每次默认创建新标签页，并关闭旧的金蝶页面。
2. 打开 `http://www.jdy.com/`。
3. 若检测到 class 为 `workstation btn-green` 的“我的工作台”，点击后跳过登录表单。
4. 否则点击官网“登录”，等待延迟加载的账号、密码、协议和登录控件。
5. 自动填写凭据、勾选协议并登录；使用 `--manual-login` 时允许人工完成提交。
6. 必须检测到“进入使用”按钮才能确认登录完成，不能依赖 URL。
7. 点击“进入使用”后进入“财务报表”，再进入“现金流量表”。
8. 若出现“现金流量表平衡检查”，只点击“我知道了”关闭提示，不执行任何重算。

## 现金流量表

1. 读取期间选项并选择数值最大的一期。
2. 点击查询；若平衡检查提示再次出现，只点击“我知道了”关闭提示。
3. 等待表格加载。
4. 只定位表头“本期金额”所在列。
5. 以 100 像素步长扫描虚拟滚动容器。
6. 收集有金额的单元格，以 `data-row-key` 去重并按业务行顺序处理。

候选行数是扫描得到的有数据单元格数；导出数不必与候选行数相等。没有调整明细弹窗的金额行会在重试后记为跳过。

## 调整列表

对每个可打开调整列表的候选行执行：

1. 选择“本年”，确认期间覆盖第 1 期至第 12 期。
2. 点击“查询”，等待多选框加载。
3. 点击第一个 `input.kd-checkbox-input` 对应的全选控件。
4. 通过复选框状态或“已选中 N 条”文本确认全选生效。
5. 点击右上角“导出”。
6. 等待下载文件完整写入后关闭调整列表，继续下一行。

## 结果分类

- 导出：调整列表成功打开，查询、全选、下载均完成。
- 跳过：金额单元格可点击，但在设定等待时间和重试次数内未打开调整列表。
- 失败：调整列表已打开，但期间、查询、全选、导出或下载核验失败。

默认失败截图写入 `工作区/rpa`，导出文件写入 `工作区/04_产出/现金流量调整导出/<时间戳>`。

## 安全边界

此流程只读并导出。禁止点击：

- 全部重算
- 批量调整
- 批量调整选中行
- 自动指定
- 重新指定
- 不指定

页面改版后如果无法区分“导出”和写入类操作，立即停止，不做模糊点击。
