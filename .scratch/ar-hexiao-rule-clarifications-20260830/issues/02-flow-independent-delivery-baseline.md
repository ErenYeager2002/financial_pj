# 02 流转匹配与盈亏核销解耦

Status: ready-for-human

Type: task

## 目标

1. 到账流转表未命中、弱命中或多命中时，只把流转写入标为人工处理，不得阻止盈亏核算表继续按智云数据判定和写入。
2. 智云最新交付额与盈亏表历史应收不一致时，结清、部分回款和超收全部以交付额为准；原应收保持不变。
3. 同一 SO/SOD 的多个父 AR 按核销记录顺序逐笔建立拆行链，流转多命中不得使该链提前变成异常。

## 验收

- `flow_hits=0` 或 `flow_hits>1` 的记录仍可进入盈亏 `auto/hold` 正常判定，流转计划继续标记 `hand`。
- 同一 SO/SOD 的多个父 AR 即使流转多命中，也能按核销记录NUM建立顺序分笔链。
- 最新交付额低于或高于历史应收时，部分回款均保留原应收，新增未结清承接行应收留空。
- 累计回款达到交付额时结清，超过交付额时仍挂账。
