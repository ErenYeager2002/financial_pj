# 01 — Controlled registry and canonical execution routes

**What to build:** Employees reach a platform-owned execution experience selected by a controlled registry, with a clear unavailable state for unregistered business Skills and compatible canonical Skill routes.

**Blocked by:** None — can start immediately.

**Status:** ready-for-human

- [x] Every published business Skill must resolve to an allowlisted experience key.
- [x] Foundation and supporting Skills are classified separately from business Skills.
- [x] An unknown or missing business experience cannot render the generic task form.
- [x] Canonical Skill execution and task routes preserve draft query context.
- [x] Existing AR and legacy run links remain usable.
- [x] Registry and route behavior have automated tests.
