# PR-04 审批入口当前身份与并发决定

## 源码修复

审批列表包含过期处理，本身也是写入口。列表与审批决定现在均在 scheduler global 锁后刷新管理员身份；决定刷新并锁定审批及工作流，当前状态不再等待审批时拒绝继续。批准前复核固定所有者当前身份/部门及 Skill 权限，拒绝审批仍允许管理员停止停用所有者的申请。输入证据刷新文件当前归属；快照变化撤销补齐实际操作者审计。

这修复了已复现的旧管理员快照、已撤销审批、取消工作流和停用所有者仍能批准问题。服务提交边界保持既有约定，状态、动作和审计仍在同一事务。没有修改实际财务判断、发布或回读算法。
