# 单工具发布

单工具的脚本、规则和提示内容更新使用 `tool` 入口，只暂停目标工具接收新任务。现有任务继续执行，目标工具无活动任务后才切换文件；其他工具继续使用。该入口不改变全站维护状态，也不重启 API、前端或 Worker。

## 使用

在 Ubuntu 部署根目录执行，只读检查不需要平台登录：

```sh
python3 deployment/deploy_platform.py tool --skill-id ar-hexiao-daily
```

目标为部署脚本真实位置所属的持久化源码中的 `skills/<skill-id>`。内容有变化时必须更新 `tool.yaml` 的版本号。不要仅修改运行容器内的文件。

获得该工具修改授权并完成针对性验证后，发布命令为：

```sh
python3 deployment/deploy_platform.py tool --skill-id ar-hexiao-daily --apply --username ADMIN_USERNAME
```

密码由终端安全输入，不接受命令行密码参数。使用正常的管理员登录会话，操作后注销本次会话，不改变其他登录。源码提交、推送、真实核销和财务写入不包含在这个命令中。

## 发布顺序

1. 检查全站为 normal、容器身份、运行工具副本、全部工具与持久镜像的一致性、版本和执行契约；与全局部署和现有工具发布共用排他锁。
2. 保存正式回滚资料，基于当前已持久化镜像构建只替换目标工具的新镜像。构建上下文只包含 Dockerfile 和该工具，不包含环境凭据备份。当前 Ubuntu 使用经验证的本地 legacy builder，不拉取镜像、不下载依赖。
3. 暂停目标工具新任务，等待该工具的运行、排队和人工确认任务结束，最多 30 分钟。超时恢复本次暂停，不取消、不重跑任务。原先已暂停的工具拒绝自动发布，不擅自启用。
4. 仅锁定目标工具的可用状态记录，按固定容器 ID 同步 API、标准 Worker 和提醒 Worker 的目标工具文件。未变化的文件保持原样。共享调度锁不覆盖文件切换过程。
5. 核对三份文件哈希和 API 注册版本，将后续启动的 BACKEND_IMAGE 指向新镜像，再恢复目标工具。已有容器保持运行；下一次单工具发布在已持久镜像上叠加，保留前次工具更新。

已加载在提醒 Worker 中的执行契约不会自动刷新，因此这个无重启入口只接受版本号变化，拒绝其他 manifest 契约变化、依赖清单变化，以及现有应收核销任务检查所使用的导入依赖变化。公共后端、前端、依赖、数据库或提醒 Worker 协议更新必须另行按实际影响安排服务发布，不能伪装成单工具脚本更新。本次安装没有更新这些公共服务。

员工端沿用现有提交拦截和管理页工具状态；本次没有增加新的员工卡片样式或前端轮询。网页内原有的源码绑定更新流程没有迁移为这个宿主机发布命令；运维代码发布应使用上述入口。

## 失败与恢复

正常异常会恢复本次切换的目标工具文件和本次修改的启动镜像配置，核验后恢复本次暂停。状态被其他管理员修改、容器被其他发布替换、恢复校验失败时停止自动覆盖，保留正式发布记录，明确要求核实状态。不会操作其他工具、释放全站维护、触发财务任务或自动重跑业务。

每次操作的正式记录保存在部署根目录 `releases/tool-<工具>-<时间>-<随机编号>/`。其中 `status.json` 保存阶段、代次、镜像、哈希和容器身份，`content/` 是发布包，`before-0..2/` 和 `env.before` 是回滚材料。目录权限为 0700，环境备份为 0600；不得输出、上传或复制环境凭据给他人。容器内暂存目录在结束时按本次精确清单清理。

进程被强杀、主机断电、控制连接不可恢复或成功日志保存失败时，不保证自动恢复。此时先查目标工具可用状态、审计中的 `deploy.tool.pause/disable/resume` 操作凭据以及 `status.json`，不要直接再次发布或重启服务。确认容器身份与记录一致，并确认工具仍由该发布暂停、代次没有外部变化后，才能处理目标工具的回滚；不得覆盖后续管理员操作。记录显示已启用且实际文件、镜像配置符合新版时，仅修复成功记录，不回滚已恢复使用的工具。恢复失败或归属不明时保持目标工具现状，其他工具继续使用。当前未提供一键强制恢复入口。

更新源码发布位置时，应一起更新宿主机部署入口的符号链接；脚本由其真实路径定位源码，不从本地工作树或临时容器取代码。

## 本次验证边界

针对发布顺序、失败恢复、权限、事务操作凭据、目标行锁、文件切换和提醒依赖隔离进行离线测试。测试使用无网络、无生产数据卷的临时容器及独立 SQLite 数据库。线上只读检查验证入口与服务健康，不为验证改动而执行真实核销或发布无关业务工具。
