# PR-04 Workflow 取消时身份与状态刷新

## 改动

取消单任务及批次时，在调度锁后读取当前用户身份、核对任务固定部门，并强制刷新任务及动作关系，避免 ORM 缓存导致取消正在原子写入的动作或覆盖已完成状态。公共取消内层覆盖独立接口、Agent 决策和聊天模型决策；Skill 运行权限撤销后仍允许有效任务发起人取消，未扩大代取消权限。

## 验证

111 项隔离 PostgreSQL 授权专项通过，包含真实锁等待、独立事务身份变化、缓存动作状态变化和 Agent/聊天决策路径。静态 diff 检查与双轴审查通过。首轮新增测试的原子状态模拟与聊天消息事务相互等待，测试超时；已将模拟变化移至入口提交之后、调度锁之前，并保留原失败记录，不当作业务故障。没有执行真实财务任务或财务写入。

候选与受限恢复镜像通过隔离 PostgreSQL 升级、重复迁移、无 DDL 运行角色、事务回滚、领取与独立进度检查。恢复镜像只允许已有回执重放，不能视为完整服务恢复。
