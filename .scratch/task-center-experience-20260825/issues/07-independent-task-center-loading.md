# 07 让任务中心各数据区独立失败和重试

Status: ready-for-human
Category: bug
Priority: P1
Blocked by: 04, 06

## Agent Brief

**Category:** bug
**Summary:** 正式任务列表或任务提醒加载失败时，另一部分仍可查看和操作。

**Current behavior:**
任务中心在一次聚合等待中读取多个数据源，任一请求失败都会让整个页面进入错误状态。用户无法查看本来已经成功返回的任务，也没有针对失败区域的重新加载操作。

**Desired behavior:**
统一正式任务列表和任务提醒作为两个独立区域加载、报错与重试。一个区域失败时另一部分继续显示；区域错误说明失败范围并提供只重载该区域的操作。筛选参数、页码和已显示数据不会因另一部分失败而丢失。

**Key interfaces:**
- 任务中心页面数据边界 — 正式任务分页与任务提醒使用独立的加载和错误边界
- 区域重试 — 只重新读取失败的数据源并保留当前 URL 查询状态
- 页面级错误 — 仅保留给认证、授权或页面本身无法建立的错误

**Acceptance criteria:**
- [x] 任务提醒请求失败时，正式任务列表、计数、筛选和分页仍正常显示
- [x] 正式任务请求失败时，已有任务提醒和提醒操作仍正常显示
- [x] 每个失败区域显示明确范围、可访问告警和独立重新加载操作
- [x] 区域重试不会重置筛选、页码或另一区域的成功数据
- [x] 两个方向的部分失败、重试成功和权限失败具有测试

**Out of scope:**
- 离线缓存或跨页面持久化服务器响应
- 忽略认证和授权失败
- 更改后端重试或 Worker 逻辑
