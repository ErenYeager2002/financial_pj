# 0006：原生 Skill 中心

状态：已采纳，2026-09-16。

用户明确要求现有固定工具与仓库 Skill 分为两个模块，仓库 Skill 按 Pi Harness 习惯直接安装，不要求作者提供 tool.yaml 或平台适配清单。

工具中心保留现有 Registry 和 Worker 流程。Skill 中心使用独立原生安装索引，安装整个 Skill 目录，保存固定源码提交；会话固定安装快照。Pi Agent 按需读取说明与引用，调用隔离命令工具，不把原生 Skill 转换为固定脚本工具。

命令由项目专用 Unix socket 沙箱服务执行。运行镜像只保留基础解释器与依赖，删除平台应用代码；容器无网络、无业务凭据、无宿主可写挂载，材料与 Skill 目录只读。工作使用有大小限制的 tmpfs，命令结束后通过受控 tar 流归档 outputs，再销毁容器。会话、材料集、命令串行锁及输出路径分别核验。

每条命令保存到既有任务表，保存输入来源和输出文件，便于审计和权限回读。结果直接与会话关联，即使模型回复失败也可从任务记录恢复。

这取代 0005 对仓库新安装项提出标准安装清单的方案；0005 中现有固定工具的对话声明仍用于工具中心，不限制原生 Skill 的制作方式。
