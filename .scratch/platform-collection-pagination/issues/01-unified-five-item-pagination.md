# 01 统一分页和滚动区

Status: ready-for-human

在平台活跃页面中接入统一重复内容分页模块，普通列表每页最多 5 项，网格和权限表按布局容量响应式分页，并保留已有服务端分页的数据边界。

## 验收条件

- [x] 通用分页模块默认每页 5 项，支持响应式页容量并处理数据变化后的页码越界。
- [x] 活跃页面的业务卡片、列表行和表格行均使用滚动区；超过 5 项时可分页。
- [x] 平台用户和 Skill 权限按各自布局容量分页；Skill 中心只使用纵向滚动。
- [x] 任务中心和取数预览等服务端分页每页请求 5 项，正式任务单页也显示页码摘要；文件中心读取全部结果后只使用纵向滚动。
- [x] 导航、标签、流程步骤、下拉选项和表单字段不受影响。
- [x] 聚焦测试、类型检查、代码规范检查和生产构建通过。
