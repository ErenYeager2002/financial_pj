# 01 整笔与分笔回款的父金额判定

Status: needs-triage

Type: task

## 待办

修订应收核销 Skill 和实现中的父回款金额校验：

1. 整笔回款：父回款金额大于或等于关联 SO 当前待核销交付额合计时，逐 SO 按交付额完成核销；超出部分保留为父回款预付款/未分配余额，不计入 SO 或 SOD 核销金额。
2. 整笔回款：父回款金额小于关联 SO 当前待核销交付额合计时，不能当作已覆盖全部订单，应挂账人工核查。
3. 分笔回款：父回款金额可以小于全部关联 SO 交付额合计，不触发整笔回款的父金额守恒挂账；按逐 SO 本次金额、剩余应收或既定顺序分配规则处理。
4. 类型缺失、关联订单不完整、金额口径不可比等情况继续保留人工核查，不因本规则放宽。

## 验收

- 增加整笔回款结余转预付款的正例。
- 增加整笔回款金额不足的挂账反例。
- 增加分笔回款金额小于关联 SO 交付额合计但可正常分配的正例。
- 校验重复核销识别、SO/SOD 累计核销、幂等写入和预付款余额审计不受影响。
