# 标准清单声明对话执行体验

本决策扩展 ADR-0004 的试点名单，使用经过验证的 conversation.mode: chat 声明选择平台内置对话体验。未知 Skill 不再仅因缺少前端硬编码 ID 而被拒绝，但必须通过统一清单、风险、能力和包内说明校验。

当前开放能力为准备草稿和查询任务状态，仅支持离线只读 Python。清单声明不会授予额外业务权限，API 仍以当前用户的授权目录和已发布清单校验。新会话采用不与 Skill id 混淆的双下划线分隔，兼容旧试点 UUID 会话。

文件上传使用清单角色与扩展名，确定性执行仍复用原 Worker。此阶段未开放任意代码前端插件、联网模型执行或安装期自动依赖下载。具体制作要求见 ../skill-package-standard.md。

## 2026-09-16：分离模块

工具中心与 Skill 中心按安装来源区分。现有工具默认 `catalog_module: tools`，仓库标准安装入口设置 `installed_skills`；该归属与 `conversation.mode` 独立，发布新版本沿用现有归属。员工只看到已发布且有权限使用的条目，管理员在 Skill 中心读取固定 Gitee 仓库目录并准备审核包，发布前不加入员工目录。
