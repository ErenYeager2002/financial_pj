# 取数确认持久预览索引

Status: ready-for-agent

## 目标

批次取数完成后只解析一次智云导出的四份 Excel。取数确认页面通过持久化预览索引完成按日期分页、搜索和异常筛选，批次状态轮询不得重复解析 Excel。

## 约束

- Excel 仍是原始业务依据，预览索引只用于只读展示。
- 预览版本由当前核销日期四份导出文件的 SHA-256 确定。
- 补取导致文件变化后必须生成新版本；新版本完整可用前不得覆盖旧版本。
- 同一任务、日期和版本只能存在一份预览。
- 任务和取数快照清理时同步清理预览。
- 权限、一次批次确认、指定日期补取和后续逐日核销行为不变。

## 公共 seam

- `GET /api/workflow-batches/{batch_id}/fetched-data`
- `GET /api/workflows/{workflow_id}/fetched-data`
- 批次取数确认弹窗的预览请求次数

## 验收

1. 相同快照第一次查询生成预览，后续分页、搜索和异常筛选不再读取 Excel。
2. 批次每 2.5 秒状态轮询不会重新请求预览。
3. 补取后文件版本变化会重建对应日期预览，旧版本不会作为当前结果返回。
4. 预览查询只反序列化当前页 AR 分组，不完整读取全部预览数据。
5. 现有单日和批次取数确认接口响应结构保持不变。
