# 应收核销多日批次一次取数

## 目标

平台在用户选择连续多个工作日时，只登录智云一次并一次取得完整日期范围的数据。取数完成后只审核一次；审核通过后，各核销日仍按日期升序独立判定、校验、生成日清并写入同一份业务工作副本。全部日期成功后生成一次范围报告。

## 业务约束

- 多日批次只接受连续工作日；单日任务保持现有行为。
- 取数使用 `date_from`、`date_to`，任一日期失败时整个批次停止。
- 每个日期保留独立四件套、判定、计划和审计结果，不合并业务计划。
- 批次拥有共享工作区，后一天看到前一天的工作簿、台账和审计文件。
- 范围取数只审核一次；补取时必须指定批次内的核销日期。
- 审核通过后先运行范围迁移审计，再从早到晚处理每日任务。
- 全部每日写入和回读成功后运行范围报告；范围报告成功后批次才成功。
- 日志、接口和页面不得回显智云凭据或客户敏感数据。

## 公共接口

- `POST /api/workflow-batches/start`
- `GET /api/workflow-batches/{batch_id}`
- `GET /api/workflow-batches/{batch_id}/fetched-data`
- `POST /api/workflow-batches/{batch_id}/fetched-data/confirm`
- `POST /api/workflow-batches/{batch_id}/fetched-data/supplement`

## 验收

1. 三个连续工作日只调用一次安全取数包装器，参数为日期范围。
2. 页面只出现一次批次取数审核，并可按日期查看四件套。
3. 审核通过后执行一次范围迁移审计，各日期严格串行。
4. 第二天复用第一天写后的工作区和台账。
5. 最后一天完成后生成范围报告；报告失败时批次不得显示成功。
6. 单日任务和非应收核销 Skill 行为不变。
