# PR-03 请求规范化阶段记录

2026-09-20，远程持久化源码新增 `backend/app/modules/execution/canonical.py`，规范版本 1。采用带类型标记的 JSON 树和 SHA-256；对象键排序，数组保留顺序及重复项，原文和 Unicode 码点保持不变。Decimal 使用不依赖当前精度上下文的固定表示；日期和带时区时间显式区分，时间统一 UTC；拒绝非有限值、不支持的集合及无时区时间。请求 key 限长并拒绝控制/不可见字符。作用域包含服务端 operation、owner、department 与固定 revision。

此模块只处理已通过 schema 校验、已补齐固定默认值的请求。它不查询 registry、不调用模型、不访问业务数据库，不自行解析今天或最新文件。接入时必须先读取已存在 reservation 的固定元数据，再比较请求；不能在重放时使用最新版本重新计算。文件绑定必须按角色包含 ID 和 SHA-256。尚未接入任务入口，不能视为已具备完整幂等保障。

使用既有隔离检查器，只读挂载源码、无网络、临时目录运行 `submission-canonical` 专项，23 项全部通过。新增文件及检查器 AST 和尾随空白检查通过。测试涉及对象顺序、数组、Unicode、Decimal 精度、非法数值、时间、作用域、文件角色/哈希、默认字段、key 和版本拒绝。
