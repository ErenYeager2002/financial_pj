# 07 管理页面独立禁用与启用 Skill

Status: completed

Blocked by: 06

## 交付

- 在管理页显示全部平台 Skill 的可用状态，不依赖源码绑定。
- 管理员可以通过按钮进入排空、完成禁用、取消禁用和重新启用。
- 危险操作要求输入对应 Skill 的确认文字；排空期间显示活动任务数。
- `failed_disabled` 保持禁用，只提示管理员检查发布记录，不提供直接启用入口。

## 验收

- 员工不能读取或修改 Skill 可用状态。
- 禁用先停止新任务；活动任务归零后才能完成禁用。
- 页面刷新后状态仍从数据库恢复，空闲排空状态可以继续完成禁用。
- 前后端测试、类型检查、构建和部署健康检查通过。
