# 应收核销任务提醒与任务中心改造

Status: ready-for-agent

## 目标

平台在工作日 09:10 使用管理员为 `ar-hexiao-daily` 指定的负责人所保存的智云凭据，执行受控的只读核销日期检查。发现回款记录后生成任务提醒；工作台显示摘要，“我的任务”显示待处理日期和真实任务记录。用户点击提醒进入现有应收核销界面，系统预选全部未成功日期，但不会自动创建或执行正式任务。

## 领域边界

- 任务提醒不是正式任务，不固定 Skill 执行快照、业务材料或写入计划。
- 只读检查只判断指定核销日期是否至少存在一条智云回款记录，并保存数量、检查时间和脱敏结果指纹。
- 只读检查不得保存客户、金额、订单编号、智云账号或密码，不得写智云，不得创建工作流。
- 正式任务继续使用 `WorkflowSession` / `WorkflowBatch`、人工检查、业务材料版本、串行处理和写入安全规则。

## 已确认规则

1. 管理员为应收核销 Skill 选择负责人；不得在代码中写死用户名。
2. 负责人配置完成后，系统立即使用该负责人已经保存的智云凭据进行后台检查。
3. 管理员与负责人都能看到检查失败、凭据缺失和提醒；管理员可以重新填写、删除和测试负责人凭据，但不能读取已保存明文。
4. 每周一 09:10 检查上周五、周六、周日；周二至周五 09:10 检查前一天；周末不定时检查。时区固定为 Asia/Shanghai。
5. 节假日、平台停机或漏跑时，从上次成功检查日期之后补查到昨天；服务恢复后立即补查。
6. 09:10 失败后在 09:40、10:40、14:10 重试。全部失败后保留失败提示和手动重试按钮。
7. 核销日期存在至少一条回款记录就生成提醒；检查失败不能视为零记录。
8. 负责人默认手动重试失败或遗漏日期；管理员可以选择最近 31 天的日期范围重新检查。
9. 同一 Skill 的多个未处理日期在一个板块内按日期升序展示，并显示每个日期的回款记录数量和最近检查时间。
10. 点击提醒只进入应收核销界面并预选未成功日期；负责人可以增减日期，打开页面不会开始取数或创建任务。
11. 正式任务创建后，对应提醒显示处理中；日期执行成功后从待办中移除；失败、取消或未提交日期继续保留。
12. 多日期批次部分成功时，只保留未成功日期。
13. 完成后智云记录数量或脱敏指纹变化时重新提醒，并标记为完成后发现变化。
14. 负责人变更时，未创建正式任务的提醒转给新负责人，已经创建的正式任务仍归原负责人；新负责人缺少凭据时暂停检查并提示双方。
15. 工作台只显示提醒摘要；“我的任务”上方展示待处理提醒与检查异常，下方保留执行中、失败和历史任务；现有“后台任务”页面暂时保留。
16. 成功提醒只从待办界面移除，数据库保留检查、完成和正式任务关联事实。

## 数据与接口

- `TaskReminderSubscription`：部门、Skill、负责人、启用状态、时区、计划时间、最后成功检查日期、下一次检查时间。
- `TaskDiscoveryCheck`：负责人、Skill、日期范围、触发方式、状态、尝试次数、下次重试时间、脱敏错误、开始和完成时间。
- `TaskReminder`：负责人、Skill、业务日期、记录数量、脱敏指纹、状态、关联工作流/批次、首次和最近发现时间、完成时间。
- 管理员接口：读取/更新负责人配置，读取检查状态，为最近 31 天发起只读检查。
- 负责人接口：读取自己的提醒，重试失败或遗漏检查。
- 工作台契约增加提醒数量、最早日期、最近检查状态。
- 任务中心契约同时返回提醒、普通 Run 和核销 Workflow/Batch 的展示数据。

## 调度与并发

- 新增独立 `discovery` Worker 入口或等价的受租约保护执行入口，不复用正式核销动作。
- 到期检查使用数据库抢占和租约，多个实例只能领取一次。
- 同一负责人的智云只读检查与正式核销取数不能并发；冲突时延迟检查。
- 自动检查与真实核销执行使用独立配置开关；开发端真实核销关闭时，不能因提醒功能自动打开。

## 验收

1. 管理员选择负责人后创建幂等订阅，负责人变更符合规则。
2. 周一、工作日、周末、节假日/停机补查和四个重试时刻有确定性测试。
3. 回款数量大于零时同一日期只存在一条提醒；零记录不显示提醒；失败显示检查异常。
4. 凭据、业务明细和绝对路径不进入接口、数据库摘要、日志或审计详情。
5. 工作台和任务中心按权限展示提醒，普通员工不能读取其他用户提醒。
6. 多日期提醒点击后安全预选日期，不自动创建任务。
7. 单日成功、批次部分成功、失败、取消和负责人变更正确更新提醒。
8. 已完成日期的计数或指纹变化会重新提醒。
9. 手动检查遵守负责人范围与管理员 31 天限制。
10. OpenAPI、迁移、后端测试、前端测试、类型检查、格式检查和生产构建通过。
11. 开发容器保持真实核销执行关闭；只读检查只有显式启用后才访问智云。
