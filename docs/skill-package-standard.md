# 原生 Skill 安装与运行说明

Skill 中心直接安装 Gitee finance-skills 仓库的原生 Skill。作者无需制作 tool.yaml、平台安装清单或固定入口适配器。

## 仓库目录

每个 Skill 放在 skills/<名称>/。SKILL.md 是说明入口，scripts/、references/、config/ 等目录按原样保留。SKILL.md 可以包含 name、description 等常用 frontmatter，也支持普通 Markdown。

## 安装和更新

管理员在 Skill 中心读取仓库目录，选择安装或更新。平台保存固定提交的完整 Skill 目录并记录安装来源，不执行安装脚本、不自动授予业务凭据。新对话使用当前安装版本，已有会话保持自己的版本快照。

现有固定工具继续留在工具中心；原生 Skill 的目录、安装记录和会话独立管理，不因同名而覆盖现有工具。

## AI 执行

Pi Agent 读取 SKILL.md，并按需读取脚本及参考文件，使用通用命令工具运行原生脚本。文件上传和选择沿用平台文件中心。

当前隔离环境提供 Python、shell 和已有数据处理依赖。Skill 原目录位于 /skill，当前选中的材料位于 /workspace/inputs，二者只读。/workspace/outputs 保存跨命令中间文件与交付文件；其他临时文件只用于当前命令。平台自动归档新增或修改的产物，提供受账号权限控制的下载入口。

每条命令最多运行 120 秒，工作区最多 512 MiB。脚本接触不到宿主源码、数据库、业务凭据或 Docker 接口，当前不开放网络。需要新依赖、浏览器、外部接口或业务写入的 Skill 可以安装，但执行所需能力须由平台另行配置；不要求作者再写一份安装清单。

## 记录和结果

每条执行命令形成独立任务记录，记录真实退出状态和产物。会话可选择查看不同执行记录；切换页面或模型回复失败后，结果仍从任务记录恢复。安装成功与业务任务执行成功分别显示。
