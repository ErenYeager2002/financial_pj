# P3-04 受控编排与 AI 任务草稿融合

状态：已完成

负责人：前后端联合

阻塞：P3-02、P3-03

## 交付

- 管理员可查看受控步骤拓扑，编辑能力另行启用。
- AI 任务草稿固定显示候选 Skill、置信度、缺失条件、参数和平台文件。
- 低置信度只澄清，不创建任务。
- 任何执行继续经过平台权限、Manifest、哈希和审批校验。

## 验收证据

- 模型不可用时手工任务路径正常。
- 非法节点、非法连接和未审批写入被服务端拒绝。
- AI 返回值不能直接改变 Run 或 StepRun 状态。

## 实施记录

- 管理员 Skill 治理页可只读查看当前部门的 WorkflowDefinition 与受控步骤拓扑；未开放自由节点、连接或代码编辑入口。
- 数据库检查约束限定步骤类型、状态、风险、Worker 池和重试语义，写入型与外部动作型标准任务继续由服务端审批规则拒绝直接执行。
- AI 草稿显示候选 Skill、置信度、参数、文件、缺失条件和校验提示；`0.595–0.599` 等边界值不会因四舍五入绕过 60% 阈值。
- 草稿确认时再次校验平台权限、Skill 版本与哈希、文件所有权与哈希及审批条件；模型响应不能直接写 Run 或 StepRun 状态。
- 模型不可用时，Skill 中心手工任务向导保持可用。
