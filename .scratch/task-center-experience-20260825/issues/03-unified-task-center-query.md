# 03 建立统一任务中心只读查询契约

Status: ready-for-human
Category: enhancement
Priority: P1
Blocked by:

## Agent Brief

**Category:** enhancement
**Summary:** 提供一个跨普通任务、应收核销日期执行和批次的分页只读查询模型。

**Current behavior:**
普通任务有独立分页接口；应收核销日期执行和批次分别返回最多若干条完整详情对象。前端必须并行读取三个集合后自行分区，无法得到跨类型的稳定排序、分页、视图状态计数或统一筛选结果。

**Desired behavior:**
后端提供 `TaskCenterItem` 与分页响应，聚合三种执行记录的列表摘要，但保留原始对象和详情接口。结果按最近更新时间倒序并使用稳定次级排序。查询支持视图状态、类型、Skill、业务日期和更新时间范围；响应同时返回当前可见范围内的状态计数。所有数据继续服从所有者、部门和管理员可见范围。

**Key interfaces:**
- `TaskCenterItem` — 包含引用类型、引用标识、详情链接所需标识、业务任务号、Skill、业务日期或日期范围、视图状态、原始状态、进度、脱敏失败摘要、创建和更新时间
- `TaskCenterPage` — 包含条目、总数、页码、页大小、总页数和视图状态计数
- 视图状态映射 — `pending`、`running`、`failed`、`succeeded`、`cancelled`，明确覆盖等待确认、排队、超时和正在取消等原始状态
- 任务中心查询服务 — 支持类型、Skill、业务日期范围、更新时间范围和视图状态组合筛选

**Acceptance criteria:**
- [x] 一次查询可以返回三种类型的任务中心条目，且每项保留正确详情目标
- [x] 跨类型结果按 `updated_at` 倒序稳定分页，不会因翻页重复或遗漏同一条记录
- [x] 状态筛选对三种类型使用同一视图状态语义，原始状态仍可用于详情和审计
- [x] Skill、业务日期和更新时间筛选均有边界与组合测试
- [x] 状态计数与当前用户可见范围一致，不泄露其他用户或部门的记录数量
- [x] 错误摘要沿用现有脱敏规则，不返回路径、凭据、URL、堆栈或业务明细
- [x] OpenAPI、生成类型、数据库查询和权限回归测试通过

**Out of scope:**
- 合并或迁移三种执行记录的数据库表
- 通过任务中心接口启动、取消或重试任务
- 将任务提醒混入已经创建的正式任务分页结果
