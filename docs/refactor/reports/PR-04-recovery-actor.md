## 问题与修改

单日重建和批次恢复此前会刷新任务所有者资格，但使用请求开始时的实际操作者身份。管理员在等待调度锁期间被停用、换部门或降权时，旧身份仍可能通过恢复判断；批次报告恢复还缺少入口固定部门检查。

backend/app/workflow_service.py 的两个恢复入口在 scheduler 锁后刷新任务，再复用 execution_actor(CREATE) 校验当前实际操作者、固定部门和 Skill 权限。任务所有者仍独立验证。批次恢复 actor 改为必填，现有 HTTP 调用传入实际用户，不再默认为任务所有者。合法同部门管理员保持允许，未改变财务恢复条件。
