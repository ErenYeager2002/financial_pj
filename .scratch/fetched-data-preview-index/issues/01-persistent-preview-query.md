# 01 持久化取数预览查询

Status: ready-for-agent

Blocked by:

为单日与批次取数确认建立按文件版本持久化的 AR 分组预览索引，并通过现有取数预览接口提供分页、搜索和异常筛选。

## 验收

- 相同文件版本只解析一次 Excel。
- 查询结果与现有接口一致。
- 补取后自动使用新版本。
- 终态清理同步删除预览。

## Comments

2026-08-25：已实现。Worker 在取数或补取完成时计算文件版本并一次性生成预览；旧任务首次读取时自动补建。分页、搜索和异常筛选使用数据库索引，不重复读取 Excel；并发首次构建通过任务行锁串行执行。终态清理会同时删除取数快照和预览。
