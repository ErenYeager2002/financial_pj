# 应收核销回款类型判定规则修订

Status: needs-triage

日期：2026-08-30

## 目标

补充父回款金额与关联 SO 交付额不一致时的分支规则，明确整笔回款和分笔回款的不同处理方式，避免把正常分笔回款误判为挂账。

## 边界

- 本事项先登记规则，不立即修改代码、Skill 或真实业务数据。
- 后续收集并核对其他挂账案例后，再统一确定实现范围和回归测试。
- 保留现有的重复核销、金额口径、币种、关联订单完整性和写前校验规则。

## 验收方向

- 整笔回款父金额足以覆盖关联 SO 当前待核销交付额时，各 SO 按交付额完成核销，差额记录为预付款/未分配余额。
- 整笔回款父金额不足以覆盖关联 SO 当前待核销交付额时，不得直接按分笔回款处理，应挂账人工核查。
- 分笔回款不以父金额与全部关联 SO 交付额合计比较；按逐 SO 明细或剩余应收金额处理，父金额小于交付额合计属于正常情况。
- 缺少回款类型、订单关联不完整或金额口径不可比时，继续挂账，不猜测。
