# 01 整笔与分笔回款的父金额判定

Status: ready-for-human

Type: task

## 已实施

修订应收核销 Skill 和实现中的父回款金额校验：

1. 整笔回款：订单已核销金额全部存在时使用其合计，全部缺失时使用完整交付额合计；父回款金额高于选定订单金额合计时，逐 SO 按选定金额处理，超出部分保留为父回款未分配余额，不计入 SO 或 SOD 核销金额。
2. 整笔回款：父回款金额低于选定订单金额合计超过 1 元时，整笔及关联 SO 挂账人工核查。
3. 分笔回款：父回款金额可以小于或大于全部关联 SO 交付额合计；按逐 SO 本次金额、剩余应收或既定顺序分配，超出部分保留为未分配余额。
4. 类型缺失、关联订单不完整、金额口径不可比等情况继续保留人工核查，不因本规则放宽。

## 验收

- 增加整笔回款结余转预付款的正例。
- 增加整笔回款金额不足的挂账反例。
- 增加分笔回款金额小于关联 SO 交付额合计但可正常分配的正例。
- 校验重复核销识别、SO/SOD 累计核销、幂等写入和预付款余额审计不受影响。
