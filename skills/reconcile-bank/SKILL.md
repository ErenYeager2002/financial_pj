# 银行流水自动对账

本 Skill 只读取上传的银行流水和总账副本，不修改源文件，也不连接银行或 ERP。

执行前确认：

1. 银行流水包含“交易日期/日期/入账日期/到账日期”之一，以及“金额/收入金额/贷方发生额/交易金额”之一。
2. 总账包含“凭证日期/日期/记账日期”之一，以及“金额/借方金额/贷方金额”之一。
3. 金额容差和日期容差符合本次对账口径。

确定性匹配规则：

1. 金额差绝对值不超过金额容差。
2. 日期差绝对值不超过日期容差。
3. 每条总账记录最多匹配一次。
4. 候选超过一条时，按日期差、金额差、原始行号依次选择，并在结果中提示。

输出：

- 匹配明细；
- 未匹配银行流水；
- 未匹配总账；
- 汇总数量和警告。

脚本计算结果是最终数据口径。大模型只能解释汇总，不得改写匹配数量和金额。
