# 核对规则

## 分组键

分组键固定为：

```text
会计期间 + U+001F + 规范现金流量项目 + U+001F + 规范凭证号
```

不得只按凭证号汇总，因为不同会计期间会重复使用凭证号，同一凭证也可能同时属于不同现金流量项目。会计期间统一为 `YYYY-MM`；无法解析或缺失时停止执行并报告行号。

## 凭证号规范化

1. 去除首尾和内部空格。
2. 将 `－`、`—`、`–` 统一为半角 `-`。
3. 去除连字符后数字段的前导零。

示例：

| 原值 | 规范值 |
|---|---|
| `记-0032` | `记-32` |
| `记－0007` | `记-7` |
| `记-32` | `记-32` |

## 项目名称规范化

先去除空格、冒号以及末尾 `(01)`、`（01）` 类行次编码，再应用以下明确映射：

| 基准明细名称 | 规范名称 |
|---|---|
| 收到的其他与经营活动的现金 | 收到其他与经营活动有关的现金 |
| 支付的与其他经营活动有关的现金 | 支付其他与经营活动有关的现金 |
| 收回投资所收到的现金 | 收回投资收到的现金 |
| 取得投资收益所收到的现金 | 取得投资收益收到的现金 |
| 投资所支付的现金 | 投资支付的现金 |
| 借款所收到的现金 | 取得借款收到的现金 |
| 偿还债务所支付的现金 | 偿还债务支付的现金 |
| 分配股利、利润或偿还利息所支付的现金 | 分配股利、利润或偿还利息支付的现金 |

不在表中的名称保持清理后的原值。若两表出现无法明确对应的新名称，报告项目集合差异并请求用户确认，不添加猜测映射。

## 金额口径

- 基准金额：同组所有“金额”求和。
- 整合金额：同组所有“流入金额 + 流出金额”求和。
- 差额：整合金额减基准金额。
- 金额一致：差额绝对值小于 `0.005`。

现金流量项目本身决定流入或流出方向；不得把不同项目合并后抵销。

## 状态

| 状态 | 条件 | 颜色 |
|---|---|---|
| 核对一致 | 笔数、金额均一致 | 不额外标色 |
| 金额不符 | 笔数一致、金额不同 | 橙 |
| 笔数不符 | 金额一致、笔数不同 | 黄 |
| 金额及笔数不符 | 金额和笔数均不同 | 红 |
| 明细表无此凭证 | 整合表有，基准表无 | 紫 |
| 整合表缺失 | 基准表有，整合表无 | 紫，仅汇总表 |

## 输出字段

在整合明细末尾追加：

1. 规范凭证号
2. 核对结果
3. 基准笔数
4. 整合笔数
5. 基准金额
6. 整合金额
7. 差额（整合-基准）

“核对汇总”包含会计期间，按状态、期间、项目、凭证号排序，列出所有非一致分组，包括整合表无法承载的缺失凭证。
