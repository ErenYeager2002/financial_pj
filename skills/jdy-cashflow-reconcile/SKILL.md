# 金蝶现金流量凭证核对

## 执行原则

以用户提供的现金流量明细表为唯一基准。使用确定性脚本按“会计期间 + 规范现金流量项目 + 规范凭证号”分组，不进行客户、摘要或金额近似匹配。

保留原始基准表和原整合表，始终输出新工作簿。不得把真实财务明细、预览图或检查文件加入 Git。

## 输入要求

准备两个输入：

- 基准明细表：`.xls` 或 `.xlsx`，包含“凭证号、现金流量项目、方向、金额”，并包含“会计期间、期间、凭证日期、日期”中的任一期间列。
- 整合表：`.xlsx`，包含工作表“合并明细”和“凭证字号、现金流量项目、流入金额、流出金额”。

运行前读取 [references/reconciliation-rules.md](references/reconciliation-rules.md)。项目名称不在明确映射中时保留原值，并在 JSON 中报告两表项目集合差异；不自行模糊匹配或新增别名。

## 运行

先调用工作区依赖加载器，取得 Node.js 和 `node_modules` 的绝对路径。然后执行：

```powershell
& "$SKILL_DIR\scripts\run.ps1" `
  -DetailPath "基准明细表.xls" `
  -MergedPath "现金流量调整明细_12表合并.xlsx" `
  -OutputPath "现金流量调整明细_凭证核对标色.xlsx" `
  -PreviewDir "临时预览目录" `
  -NodeExe "<工作区依赖中的 Node.js 路径>" `
  -NodeModulesPath "<工作区依赖中的 node_modules 路径>"
```

`run.ps1` 在基准文件为旧版 `.xls` 时，通过本机 Excel 只读转换临时副本；转换副本和依赖 junction 会在结束时清理。

## 判定

在同一会计期间内，将 `记-0032`、`记-32` 等凭证号数字前导零差异视为同一凭证。不同会计期间的同号凭证分别核对。对每个分组比较：

1. 基准笔数与整合笔数。
2. 基准“金额”合计与整合“流入金额 + 流出金额”合计。
3. 金额差绝对值小于 `0.005` 时视为金额一致。

输出颜色：

- 红色：金额与笔数同时不符。
- 橙色：仅金额不符。
- 黄色：仅笔数不符。
- 紫色：一方缺失；整合表缺失的凭证只出现在“核对汇总”。

## 验证

核对脚本输出的 JSON 计数，并执行：

```powershell
node --test "$SKILL_DIR\tests\*.test.mjs"
```

检查以下结果：

1. 输出包含“合并明细”和“核对汇总”两个工作表。
2. 合并明细追加规范凭证号、核对结果、双方笔数、双方金额和差额列。
3. 预览中至少检查一行红色异常和一行核对一致记录。
4. 公式错误扫描为零。
5. 最终工作簿可由 Excel 只读打开。

完成后删除预览和检查副产物，仅交付最终 `.xlsx`。
