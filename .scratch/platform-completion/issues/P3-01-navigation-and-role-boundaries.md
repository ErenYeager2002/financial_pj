# P3-01 生产导航与平台角色边界

状态：已完成

负责人：主任务

阻塞：无

## 交付

- 建立可测试的生产导航公共接口。
- 由服务端平台会话决定 `finance_user` 与 `skill_admin` 菜单。
- 侧栏和命令面板使用同一份导航结果。
- 隐藏模板演示入口，更新面包屑词汇。

## 验收证据

- 导航结构测试先失败后通过。
- `pnpm typecheck`、相关 lint 和 `pnpm build` 通过。
- 两种角色的菜单快照符合规格。

## 实施记录

- 服务端读取平台本地角色，并为侧栏和命令面板生成同一份生产导航。
- 员工菜单限定为工作、Skill、任务、文件、AI 和账号；管理员增加待办、Skill 治理、组织与成员。
- Skill 中心与发布维护拆分为独立页面，模板演示和账单入口不再出现在生产导航。
- 导航结构测试 5 项、定向 lint、格式检查、TypeScript 和 Next.js 生产构建通过。
- Standards 与 Spec 两轴复核完成，最终均无遗留发现。
