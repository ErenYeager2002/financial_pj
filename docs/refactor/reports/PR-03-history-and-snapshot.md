# PR-03 历史分析与快照固定

2026-09-20，在线上 API 容器通过显式 PostgreSQL READ ONLY 事务执行历史 SELECT，附 15 秒 statement_timeout、2 秒 lock_timeout。查询仅覆盖 runs，不修改记录。分析器通过合成数据隐私与分组检查后运行。输出见 PR-03-history.json，仅包含计数、任务 ID 和 SHA-256 摘要，不输出原始 key、身份、命令或文件绑定。

当前 302 条任务中 Native 295 条，普通 7 条；295 条 Native key 均满足已验证的 64 位小写十六进制旧格式。Native 31 个重复组均存在不同存储输入摘要。普通重复组、空 key、同 owner/key 跨部门组均为 0。Native 共用 key 表示会话，必须保留各次执行，不得合并。分析结果为当前快照，回填前需重新检查。历史摘要不是 canonical v1 指纹，不用于自动绑定旧记录。

快照源码修改：公开 registry 的同算法目录 hash 函数；复制前校验固定 hash；复制到唯一 staging，复制符号链接本身而不跟随，再拒绝其中的链接；校验 staging 和复制后的源目录都匹配原 pin，才重命名发布。仍保留既有 hash 忽略目录政策，未宣称覆盖其内容或防御恶意进程持续修改磁盘。注册版本、复制中源变化、暂存内容变化、源恢复但副本内容不符均有专项测试。
