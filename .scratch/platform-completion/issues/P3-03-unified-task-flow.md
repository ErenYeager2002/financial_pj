# P3-03 统一任务入口与步骤时间线

状态：已完成

负责人：前后端联合

阻塞：P3-01、P3-02

## 交付

- 工作台、Skill 中心和 AI 助手进入同一任务向导。
- 任务详情显示业务步骤、任务事件、审批、文件及结果。
- 业务事件与技术错误分层显示。

## 验收证据

- 从三个入口创建的任务进入同一详情页。
- 员工只能读取本人任务步骤和平台文件。
- 失败步骤明确显示可否重试及原因。

## 实施记录

- 工作台和 Skill 中心进入 `SkillRunSetup`；AI 助手只生成草稿并跳转同一 Skill 任务向导，不再直接确认创建任务。
- 任务详情通过统一 React Query 数据层显示 Run、步骤时间线、审批、输入输出文件、结果和 SSE 事件；非终态步骤与审批按受控频率刷新。
- 标准 Run 初始化参数校验、文件校验、Skill 执行、结果预览和产物归档五个步骤；取消、预检失败、Worker 执行、超时和租约恢复均同步步骤状态。
- Run 详情、步骤、审批和 SSE 统一使用递归脱敏，隐藏敏感键、内联凭据、绝对路径和堆栈；跨用户、跨部门读取回归通过。
- 前端统一任务向导与数据层测试 5 项通过，后端相关回归及全量测试通过。
