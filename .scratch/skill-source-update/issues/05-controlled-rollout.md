# 05 单 Skill 受控发布与恢复

Status: completed

Blocked by: 03, 04

## 交付

- 实现后台 Skill 发布任务和逐阶段状态记录。
- 接入原子目录切换、Registry 刷新、哈希验证和失败恢复。
- 成功后更新当前发布指针并重新启用 Skill。

## 验收

- 重复点击幂等，每个 Skill 同时只有一个发布任务。
- 安装或验证失败恢复原版本并验证原哈希。
- 恢复验证失败保持禁用。
- 当前发布记录与运行目录一致且只有一个当前版本。
