# 应收账款合并与销售拆分

一次上传材料后选择模式：

- `仅合并`：应收 all 和领导部分版。
- `合并并按销售拆分`：应收 all、领导部分版和销售人员工作簿 ZIP。
- `已有应收 all 直接拆分`：销售人员工作簿 ZIP。

合并产生的应收 all 会在同一次任务中直接传给拆分脚本，使用者不需要重复下载和上传。原始文件不会被覆盖，拆分结果必须通过行数对账。

合并结果的 `透视汇总` 是原生可刷新的数据透视表，数据源绑定 `主表` 的 `A1:Q1048576` 范围。向 `主表` 末尾追加新行后，在透视表中执行刷新即可更新；原生透视表生成成功时，同一工作簿中的 `透视汇总_静态备份` 用于生成结果时的核对。
